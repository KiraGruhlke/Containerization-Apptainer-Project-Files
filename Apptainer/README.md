# Apptainer-Projekt: spacemed

Dieses Projekt soll die grundlegende Nutzung von Apptainer u. a. anhand des Python-basierten Beispielprojekts `spacemed` zeigen.

Enthaltene Teile sind:
1. `apptainer-container-erstellen.md` (in `~/Apptainer/spacemed`)
2. `daten-directory-binden.md` (in `~/Apptainer/spacemed_data`)
3. `multiprocessing.md` (in `~/Apptainer/spacemed_data`)
4. `gpu-unterstuetzung.md` (in `~/Apptainer/gpu_test`)
Dies sind kurze Markdown-Anleitungen.

Weitergehende technische Hintergründe und Erklärungen finden sich `Technical Report to Containerization with Apptainer.pdf` (in `~/Apptainer`).
